# Wata

This repository holds the website for [Wata](https://wata.ctsite.cc/), an iPhone and Apple Watch app that reminds you to drink water by looking at your progress rather than the clock, and logs a glass when you tap your phone on an NFC sticker on your bottle. It is also Wata's issue tracker.

The app's source code is not published here. Wata will come from the App Store.

## Help, bugs and requests

Open an issue: <https://github.com/tasict/wata/issues>

It helps to include:

- your iPhone model, iOS version and Wata version (Settings › About)
- what you expected and what happened instead

Issues are public, so leave out anything you would not want others to read.

## The website

Plain static HTML, served by GitHub Pages at <https://wata.ctsite.cc/>. There is no build step: what is in this repository is what the site serves.
