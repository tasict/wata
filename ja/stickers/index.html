どのシールを買えばいい？

チップさえ合えば、どの NFC シールでも使えます。コーヒー1杯分で数枚買えます。購入前に、商品説明に次の内容があるか確認してください。

使えるもの

NTAG213、NTAG215、NTAG216

NFC Forum Type 2、13.56 MHz、書き換え可能。NTAG213 で十分です。Wata のリンクは約40バイトです。

金属対応（金属ボトル用）

ステンレスやアルミに普通のシールを貼ると読み取れません。金属対応のものはフェライト層が入っています。プラスチックやガラスならどれでも使えます。

防水、直径25〜30 mm 程度の丸形

PET やエポキシのシールは手洗いなら大丈夫。食洗機には入れないでください。

使えないもの

125 kHz の RFID（EM4100、T5577）

ドアや駐車場用のタグです。NFC ではないため、iPhone では読めません。

MIFARE Classic 1K

入館カードによく使われるチップ。iPhone からは書き込めません。

ロック済み・読み取り専用のシール

すでに誰かが書き込んだもの。ショートカット App 経由なら記録できますが、かざすだけでは Wata が開きません。

探し方

「NTAG213 NFCシール」で検索。金属ボトルなら「金属対応 NTAG213」。

ペアリングのしかた

  1. Wata で「設定 › ステッカー › ステッカーを追加」を開きます。
  2. iPhone の背面の上のほうをステッカーに当てて、そのまま動かさずに。Wata がリンクを書き込み、ステッカーの ID を控えます。
  3. どんな容器かを入力します。名前、容量、中身。
  4. 試しに一度かざします。以降は画面がついている状態でかざし、バナーをタップするだけ。

家族でひとつのステッカーを共有できます。それぞれの iPhone でペアリングすれば、iPhone ごとに記録されます。あなたの iPhone でペアリングしていないステッカーが、あなたの記録になることはありません。

読み取り部の位置

どの iPhone も、NFC アンテナは背面の上端、カメラのそばにあります。その部分をステッカーに当ててください。厚いケースや MagSafe リングは邪魔になります。iPhone Duo は先に閉じてください。
